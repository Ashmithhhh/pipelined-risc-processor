01

CLOCK JOURNEY

What happens on every cycle

  1. IFRead instruction at PC and calculate PC + 4.
  2. IDDecode opcode, read rs/rt, extend immediate and detect load-use hazards.
  3. EXSelect forwarded operands, run the ALU and resolve BEQ.
  4. MEMRead or write data RAM using the ALU result as an address.
  5. WBSelect memory data or ALU result and update the destination register.
02

HAZARD SYSTEM

How correctness is preserved

ALU dependencyForward EX/MEM first, then MEM/WB, with no stall.
Load-use dependencyFreeze PC + IF/ID and inject one ID/EX bubble.
Taken BEQResolve in EX, redirect PC and flush two younger instructions.
JumpResolve in ID, redirect PC and flush the sequential fetch.
